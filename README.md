## О чём проект
Проект следует статье  
https://arxiv.org/pdf/2602.04479  

Цель — изучить задачи машинного обучения,
которые могут быть записаны в виде задачи (P)
с аффинными связующими ограничениями,
и проверить, можно ли уменьшить сложность решения
*без изменения самой задачи*,
а только за счёт её эквивалентной переформулировки.

## Что сделано на первой итерации
- Реализована toy-задача Horizontal Federated Learning  
  (квадратичная задача консенсуса с аналитическим решением).
- Проведён sanity-check влияния графа коммуникации  
  (ring / grid / ER / BA / small-world)
  на скорость сходимости децентрализованных алгоритмов.
- Показано, что топология сети существенно влияет
  на скорость согласования между агентами.

**Основной артефакт:**  
- `code/notebooks/01_sanity.ipynb`

## Следующий шаг
Сравнение двух эквивалентных формулировок одной и той же задачи (P)
и анализ влияния формы записи на итерационную
и коммуникационную сложность.
